
# API de Estoque

API REST desenvolvida em Python com FastAPI
para gerenciamento de produtos e estoque.

## Tecnologias

- Python 3.12
- FastAPI
- Uvicorn

## Executar

Instale as dependências:

```bash
pip install -r requirements.txt
```

Inicie a API:

```bash
uvicorn app.main:app --reload
```

Acesse a documentação em http://localhost:8000/docs.
